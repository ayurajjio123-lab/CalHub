# CalcHub

Mobile-first all-in-one calculator app packaged for Codemagic/Android WebView.

## Included
- Basic + scientific calculations
- Graphing Calculator: function plotting, roots, value table, derivative estimate, Simpson-rule integral estimate
- Equation Solver: linear/quadratic step-by-step solving plus numerical root search for larger equations
- Finance, conversion, date, health and utility calculators
- Responsive mobile UI with light/dark themes
- Branded favicon and Android launcher icon
- Animated mobile splash screen
- Codemagic YAML workflow

## Example equations
- `2x^2 - 7x + 3 = 0`
- `(x+3)(x-2)=0`
- `3x^4 - 2x^2 + 7x - 5 = 0`

## Example graph expressions
- `x^2 - 4*x + 3`
- `sin(x)`
- `x^3 - 2*x`

The graph and equation tools run offline in the app; no external math library is required.
